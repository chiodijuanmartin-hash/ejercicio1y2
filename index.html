Callbacks vs. Promises

Actividad 1 · JavaScript asíncrono

¿Qué vamos a aprender?

Algunas tareas tardan en terminar. Por ejemplo, una aplicación puede necesitar esperar una respuesta de un servidor. JavaScript permite organizar esas tareas con callbacks y Promises.

1. Callback

function buscarUsuario(callback) {
  setTimeout(() => {
    callback("Encontré a Mica");
  }, 700);
}

buscarUsuario((mensaje) => {
  console.log(mensaje);
});

¿Cómo funciona en palabras simples?

Un callback es una función que le entregamos a otra función para que la ejecute más tarde.

En este ejemplo, buscarUsuario simula una búsqueda. Después de 700 milisegundos, ejecuta la función que recibió y le pasa el mensaje.

Dicho de forma natural: “Cuando termines la búsqueda, avisame usando esta función”.

Si hay muchas tareas encadenadas, los callbacks pueden hacer que el código sea más difícil de leer.

2. Promise

function buscarUsuario() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve("Encontré a Mica");
    }, 700);
  });
}

buscarUsuario()
  .then(mensaje => console.log(mensaje))
  .catch(error => console.error(error));

¿Cómo funciona en palabras simples?

Una Promise representa un resultado que todavía no está disponible, pero que llegará más adelante o terminará en un error.

resolve indica que la operación terminó correctamente. reject indica que falló.

.then() recibe el resultado exitoso y .catch() permite manejar un error.

Dicho de forma natural: “Prometo darte el resultado cuando termine; si algo falla, te aviso”.

Conclusión

Los callbacks permiten ejecutar una función después de una tarea. Las Promises representan resultados futuros y ofrecen una estructura clara para continuar el proceso o manejar un error.
